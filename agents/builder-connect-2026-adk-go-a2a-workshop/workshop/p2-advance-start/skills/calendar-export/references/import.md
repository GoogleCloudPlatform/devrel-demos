# Importing an .ics file

First get the file onto your computer. In Cloud Shell, run
`cloudshell download my-plan.ics` in the step's folder, or right-click the
file in the Cloud Shell Editor and choose Download.

- **Google Calendar:** Settings (the gear icon) → Import & export → Import.
  Select the file, choose a calendar, and click Import.
- **Outlook:** open the file, or drag it onto the calendar, and confirm.
- **Apple Calendar:** File → Import, then select the file.

The events are in UTC, so every app shows them at the right local time.
