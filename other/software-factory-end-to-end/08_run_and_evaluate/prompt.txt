Build a Python module for food stall queue management and pricing:
1. Wait Time (`calculate_wait_time`):
   - Standard order: 3.0 minutes prep time.
   - Custom order (`is_custom=True`): 4.5 minutes prep time (+50%).
   - Total wait = sum of prep times in orders list.
2. Surge Pricing (`calculate_surge_price`):
   - Queue <= 5: 1.0x (standard base price).
   - Queue > 5: 1.2x (surge price).
3. Validation:
   - Negative queue lengths or negative prices raise ValueError.
   - Base prices over 100.0 raise ValueError.
   - Round final currency and time amounts to 2 decimal places.
Write the code, run pytest in your sandbox, and report verified results.
