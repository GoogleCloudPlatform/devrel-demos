# Formula E Multi-Agent Track Planner: Codelab Assets

Assets for the
[Build a Multi-Agent Formula E Track Planner with ADK & A2A](https://codelabs.developers.google.com/formula-e-build-multi-agent-track-planner)
codelab.

This folder is **not** a complete project. In the codelab you generate two
projects with [`agents-cli`](https://google.github.io/agents-cli/) and copy
these files into them:

| Folder | Copy into | Contents |
| :--- | :--- | :--- |
| `track-planner/` | `agents-cli scaffold create track-planner` | Domain tools, A2A client auth, venue data, FIA skill reference and script, unit tests, eval datasets |
| `gatekeeper/` | `agents-cli scaffold create gatekeeper` | Homologation checklist tool and unit tests |
| `solution/` | Either project, to catch up | Finished versions of the files you write in the codelab |
