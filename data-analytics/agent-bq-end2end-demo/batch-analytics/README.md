# Batch Analytics: Real-Time Telemetry & AI.AGG

This folder contains resources for compiling and analyzing runtime traces and telemetry generated by our conversational multi-agent system.

---

## Directory Contents

*   `run_analytics_demo.py`: A command-line Python script that runs the batch analytics demo step-by-step, showing SQL queries, explaining their function, displaying results, and pausing for keypresses between stages.
